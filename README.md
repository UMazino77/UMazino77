## 🚀 Featured projects

### 📝 [01Blog](https://github.com/UMazino77/[01blog])
A fullstack social blogging platform where students share their learning journey.
- **Backend:** Java Spring Boot REST API with JWT/Spring Security authentication and role-based access (user vs admin)
- **Frontend:** Angular with a responsive UI, feed, likes, comments, and notifications
- **Features:** public profiles, subscriptions, media upload, user reports, and an admin moderation dashboard
- **Database:** relational SQL for posts, likes, comments, and subscriptions

### 💣 [bomberman-dom](https://github.com/UMazino77/bomberman-dom)
A real-time multiplayer Bomberman for 2 to 4 players, with characters inspired by One Piece.
- Built on the **mini-framework my team and I created**, with no canvas and no game engine
- Lobby with player counter and countdown, power-ups, 3 lives, and live chat over **WebSockets**
- Steady **60 FPS** using `requestAnimationFrame`, with state synchronized across players

### 🐚 [0-shell](https://github.com/UMazino77/0-shell)
A mini Unix shell written in **Rust**.
- Implements core shell behavior and commands from scratch
- Systems-level programming: process handling, parsing, and error handling
